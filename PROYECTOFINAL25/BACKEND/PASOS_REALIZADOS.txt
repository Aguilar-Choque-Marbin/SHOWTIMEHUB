========================================
✅ PASO 1: INICIALIZAR PROYECTO NODE.JS
========================================

Comandos ejecutados:
  1. cd BACKEND
  2. npm init -y
  3. npm install express pg dotenv bcrypt jsonwebtoken cors
  4. npm install --save-dev nodemon

Paquetes instalados:
  - express          → Framework para crear la API REST
  - pg               → Conectar con PostgreSQL
  - dotenv           → Variables de entorno (.env)
  - bcrypt           → Encriptar contraseñas
  - jsonwebtoken     → Autenticación JWT
  - cors             → Permitir peticiones desde el frontend
  - nodemon (dev)    → Reinicia servidor automáticamente

Archivos creados:
  ✅ package.json
  ✅ package-lock.json
  ✅ node_modules/
