# ShowTime Hub - Frontend

Frontend desarrollado en Vue.js 3 para la plataforma ShowTime Hub que conecta artistas con clientes.

## 🚀 Tecnologías Utilizadas

- **Vue.js 3** - Framework JavaScript progresivo
- **Vite** - Build tool y dev server rápido
- **Vue Router** - Enrutamiento SPA
- **Pinia** - State management oficial de Vue
- **Axios** - Cliente HTTP para conectar con API REST
- **Tailwind CSS** - Framework CSS utility-first
- **ESLint + Prettier** - Linting y formato de código

## 📡 Conexión con Backend

El frontend se conecta al backend en `http://localhost:3000/api`

**Importante**: Asegúrate de tener el backend corriendo antes de iniciar el frontend.
